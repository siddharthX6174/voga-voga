# voga voga - Enterprise Intelligence Copilot

**voga voga** is a modern, AI-powered enterprise assistant built to help organizations navigate internal policies, perform calculations, and manage chat history through an intuitive, futuristic web interface.

## 🚀 Features

- **Agentic Workflow:** Utilizes LangGraph and Google's Gemini LLMs to intelligently route user queries to the appropriate tools (Policy Search vs. Metric Calculations).
- **Retrieval-Augmented Generation (RAG):** Upload and parse PDF documents directly from the UI. Documents are chunked and embedded into a local ChromaDB vector database using `models/gemini-embedding-2` for instant policy retrieval.
- **Dynamic Session Management:** Start new chats and browse history from a sleek sidebar. Session titles are dynamically generated by the AI based on the context of your first message.
- **Premium UI/UX:** A stunning, fully responsive frontend featuring a vibrant animated gradient background, frosted glass (glassmorphism) chat elements, and modern typography using the Outfit font.

## 💻 Tech Stack

### Frontend
- HTML5, Vanilla JavaScript, CSS3
- Google Fonts (Outfit, Inter)

### Backend
- **Framework:** FastAPI, Uvicorn
- **Database:** SQLite (via SQLAlchemy)
- **AI/LLM:** Google Generative AI (`gemini-3.6-flash`)
- **Orchestration:** LangChain, LangGraph
- **Vector Store (RAG):** ChromaDB, PyPDFLoader

## 🛠 How to Run

You will need two separate terminal windows to run the frontend and the backend simultaneously.

### 1. Start the Backend
Navigate to the `backend` directory and activate your virtual environment:
```bash
cd backend
# Activate venv (Windows)
.\venv\Scripts\activate
# Start the FastAPI server
python -m uvicorn api.main:app --reload
```
*The backend will run on `http://127.0.0.1:8000`.*

### 2. Start the Frontend
In a new terminal window, navigate to the `frontend` directory:
```bash
cd frontend
# Start a simple HTTP server
python -m http.server 3000
```
*Access the application at `http://localhost:3000`.*
